Smart Campus Complaint Management System
A web-based platform designed to streamline issue reporting, track maintenance tasks, and automate resolution workflows across university campuses.

Features
For Students & Faculty
Easy Issue Reporting: Submit tickets categorized by domain (IT/Wi-Fi, Electrical, Plumbing, Hostel, Cleanliness, Classroom Tech).

Location Mapping: Specify building, floor, and room details along with photo/video attachments.

Live Ticket Tracking: Monitor issue progress in real time (Submitted ➔ Assigned ➔ In Progress ➔ Resolved).

Feedback System: Rate completed resolution work and leave comments.

For Maintenance Staff
Work Order Queue: View and filter tasks assigned directly to your department.

Status Updates: Update ticket progress, upload completion photos, and log resolution notes.

For Campus Administrators
Role-Based Access Control (RBAC): Separate portals and permissions for students, technicians, and administrators.

Automated Ticket Routing: Auto-assign issues to specific departments based on selected categories.

SLA & Analytics Dashboard: Monitor average resolution times, active/overdue tickets, and service performance trends.

Tech Stack
Frontend: Next.js (React), TypeScript, Tailwind CSS

Backend: Node.js / Next.js API Routes

Database: PostgreSQL with Prisma ORM (or Firebase / MongoDB)

Authentication: NextAuth.js (supporting Campus SSO / OAuth2)

File Storage: AWS S3 or Cloudinary (for media evidence uploads)

Getting Started
Prerequisites
Node.js (v18.x or higher)

PostgreSQL database instance

npm or pnpm
